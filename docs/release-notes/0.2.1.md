# ConvertKit 0.2.1

A faster, smaller build with a few interface fixes.

## Faster

- **JPEG to a target size**: 4.6× faster than 0.2.0. The search for the right quality now takes at most four encodes.
- **Optimize image**: 2.2× faster for JPEG. Candidates are encoded in parallel, and each source is decoded only once.
- **PDF work**: exporting PDF pages renders them in parallel, and compression recompresses images across threads.
- **Smaller app**: the app binary dropped from 26 MB to 20 MB.

Every benchmark output is byte for byte the same as 0.2.0's. The full benchmark is in `docs/performance.md`.

## Fixes

- The dashboard scrollbar no longer covers the edge of the content.
- When the aspect ratio is locked, a link icon between the width and height fields shows that they change together.
- Tidier Finder action rows and recipe text, and a smoother animation for toast messages.
