# ConvertKit 0.2.0

Every file tool now works out of the box. ConvertKit no longer asks you to install anything with Homebrew: the engines it needs ship inside the app.

## Works without Homebrew

- **Images**: converting, resizing and optimizing use macOS's own ImageIO through a bundled helper, with in-process encoders for the rest. ImageMagick is never required; it is used, if installed, only for AVIF or HEIC output on a macOS release whose ImageIO cannot encode them.
- **Video and audio**: conversion, compression, target-size and quality tools run on a bundled FFmpeg, built from pinned, checksummed sources.
- **Transcription**: Transcribe runs on the bundled Whisper runtime and FFmpeg and writes every transcript format (TXT, SRT and VTT).
- **PDFs**: every PDF tool works. A bundled PDFKit helper reads, renders and extracts text; split, combine and compress run in the app with lopdf and mozjpeg.
- **Documents**: conversion uses the bundled Pandoc 3.12.1 and Tectonic 0.17.0. DOCX to PDF still uses LibreOffice when it is installed, because it keeps the layout, and otherwise falls back to Pandoc.

## Good to know

- **Bigger download.** The DMG is about 62 MB larger, mostly Pandoc and Tectonic.
- **Your first PDF from a document needs internet.** Tectonic downloads the TeX support files it needs the first time it builds a PDF, then caches them. Later PDFs work offline.
